# ADR-002: RRF 主导、交叉编码器加权融合的重排策略

## Status: Accepted (2026-09-24)

## Background

混合检索的通行做法是"双路召回 → 交叉编码器重排 → 直接采信重排顺序"。
实测发现：当交叉编码器在查询语言上偏弱（英文 reranker + 中文查询）时，
直接采信其排序会让正确答案被无人制衡地压掉——中文查询 top-1 命中率
从 11/12 掉到崩盘。

## Decision

1. 双路召回结果用 RRF（k=60）融合，RRF 分数是最终排序的**主导信号**。
2. 交叉编码器分数只做 min-max 归一化后按权重 w（默认 0.4，上限钳制 [0,1]）
   融入：`final = (1-w)*norm(RRF) + w*norm(CE)`。
3. 重排器永远不得单独决定最终顺序。该规则写入 Spec 验收标准并由
   `tests/test_fusion.py` 的 blend 权重边界测试守护。

## Consequences

- 正面：重排器偏弱时 RRF 兜底，检索质量有下界保证
- 正面：重排器强时仍能提升排序（w 可调）
- 负面：多一次归一化计算，成本可忽略
