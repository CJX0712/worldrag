# 安全与合规规范

WorldSaaS 平台遵循等保三级与 ISO 27001 标准。所有用户密码使用 bcrypt 算法加盐哈希存储，成本因子为十二。登录接口启用图形验证码与滑块验证双重防护，连续五次密码错误将锁定账户三十分钟，锁定期间即使密码正确也无法登录。

数据传输全程使用 TLS 1.2 及以上版本加密，静态数据使用 AES-256 加密存储。密钥由独立的密钥管理服务托管，每九十天自动轮换一次。平台不存储用户的明文支付信息，支付环节由持牌第三方支付机构处理，符合 PCI DSS 要求。

权限模型采用基于角色的访问控制，预置角色包括系统管理员、空间管理员、普通成员与只读访客。敏感操作如数据导出、批量删除、权限变更必须完成二次身份验证。所有敏感操作均记录审计日志，审计日志保留一百八十天，支持按操作人、操作类型与时间范围检索。

安全漏洞响应承诺：严重级别漏洞二十四小时内修复，高危级别七十二小时内修复，中低危级别纳入下一个迭代版本。漏洞上报渠道为安全邮箱，白帽子提交的有效漏洞可获得现金奖励。
