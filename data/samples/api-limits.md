# API 限流与配额规范

WorldSaaS 开放平台对所有 API 端点实施分层限流。免费版用户的默认配额为每分钟六十次请求，每日上限一万次。专业版用户的配额为每分钟六百次请求，每日上限五十万次。企业版用户的配额可与平台协商定制，默认不低于每分钟三千次。

当请求超出配额时，API 返回 HTTP 429 状态码，响应体中包含 retry_after 字段，指示客户端应当等待的秒数。客户端必须实现指数退避重试策略，首次重试等待一秒，之后每次翻倍，最多重试五次。连续触发限流超过十次的客户端将被临时封禁十五分钟。

批量接口单次请求最多携带一百条记录，超出部分将被截断并在响应头的 truncated 字段中标记。所有 API 请求必须携带有效的 Bearer 令牌，令牌有效期为两小时，过期后需使用刷新令牌重新获取。刷新令牌有效期为三十天，滚动更新。

数据导出接口为异步接口，提交导出任务后返回任务编号，客户端应通过轮询任务状态接口获取结果，轮询间隔不得低于五秒。导出文件保留七十二小时，过期自动删除。
